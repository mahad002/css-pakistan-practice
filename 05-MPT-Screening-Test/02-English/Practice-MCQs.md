# English: Practice MCQs

Written for the MPT English section (50 marks): vocabulary, grammar usage and comprehension. Question types follow the real papers: synonyms, antonyms, analogies, sentence correction, prepositions, idioms, sentence completion with confusing word pairs, and short passages. Aim for 30 seconds a question outside the passages.

Total questions: **300**. Each question has one correct option. The answer key with one-line explanations is at the end of this file.
