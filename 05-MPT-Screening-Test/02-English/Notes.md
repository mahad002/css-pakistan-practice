# English: High-Yield Notes

50 marks. Target 40. The same material feeds the 20 MCQs of the English Precis and Composition paper.

Typical split in the real paper: vocabulary 15–20, grammar and usage 10–15, prepositions 5, idioms 4–5, analogies 4, sentence completion 4, comprehension 5–10, and in 2027 a few Urdu-to-English translation items.

---

## 1. How to answer each question type

| Type | Method |
|---|---|
| Synonym or antonym | Read the instruction twice: many marks are lost by picking a synonym when the antonym was asked. If you do not know the word, look at its root and prefix, then rule out options that are synonyms of each other (both cannot be right). |
| Correct sentence | Check in this order: subject-verb agreement, tense, pronoun case, modifier position, parallel structure, preposition. |
| Preposition | Say the phrase aloud in your head. Fixed combinations sound wrong when the preposition is wrong. Learn the list in section 5. |
| Idiom | The literal meaning is always a wrong option. |
| Analogy | Make a short sentence linking the first pair ("A scribe produces a manuscript") and apply the same sentence to the options. |
| Two-blank completion | Test the easier blank first and delete options. Look for signal words: "but", "although", "whereas" (contrast); "and", "so", "therefore" (same direction). |
| Comprehension | Read the questions first, then the passage once. The answer must be supported by words in the passage, not by what you know. Options with "always", "never", "only" are usually wrong. |
| Translation | The right option keeps the tense, the condition ("if ... had") and the negation of the Urdu sentence exactly. |

## 6. Grammar rules that are tested

**Subject and verb**

- "Each", "every", "either", "neither", "one of", "everybody" take a singular verb.
- "Either ... or", "neither ... nor": the verb agrees with the nearer subject.
- "The number of" is singular. "A number of" is plural.
- "As well as", "along with", "together with": the verb agrees with the first subject.
- "News", "mathematics", "physics", "politics" (as a subject) are singular. A sum of money, a distance or a period treated as one amount is singular.
- "One of those who" is followed by a plural verb.
- Uncountable nouns have no plural: advice, information, furniture, luggage, scenery, poetry, equipment.

**Tenses**

- "Since" + point of time, "for" + period, both with a perfect tense.
- The earlier of two past actions takes the past perfect.
- No future tense after "when", "if", "unless", "until" in a time or condition clause: "I shall call you when he comes."
- State verbs (know, believe, own, belong, see, hear) are not used in continuous tenses.

**Conditionals and unreal forms**

| Type | Form | Example |
|---|---|---|
| First (possible) | if + present, will | If it rains, we will stay. |
| Second (unreal present) | if + past, would | If I were rich, I would travel. |
| Third (unreal past) | if + had + past participle, would have | If he had run, he would have won. |
| Inverted | Had / Were / Should + subject | Had I known, I would have come. |

- "I wish", "as if", "it is high time", "would rather + subject" take the past tense for a present meaning.
- "Lest" is followed by "should": "Work hard lest you should fail."

**Inversion after negative openers**

"Hardly / Scarcely had he ... when"; "No sooner had he ... than"; "Never have I ..."; "Not only did he ... but also"; "Seldom does he ...".

**Comparison**

- Comparative for two, superlative for three or more.
- No double comparatives ("more better" is wrong).
- "Senior, junior, superior, inferior, prior, prefer" take "to", not "than".
- "Unique", "perfect", "round" have no degrees.

**Pronouns**

- After a preposition use the object form: "between you and me".
- "Who" for a subject, "whom" for an object.
- "One" is followed by "one's".

**Modifiers and parallel structure**

- An opening "-ing" or "-ed" phrase must describe the subject that follows: "Walking home, I saw a fire", not "Walking home, a fire was seen".
- Items in a list or joined by "and", "or", "not only ... but also", "both ... and" must have the same grammatical form.

**Articles**

- "An" before a vowel sound (an hour, an MA, an honest man). "A" before a consonant sound (a university, a European, a one-rupee note).
- "The" with rivers, seas, oceans, mountain ranges, deserts, newspapers, holy books, superlatives, unique things, and country names that are plural or contain "republic", "kingdom" or "states".

**Voice and narration**

| Active tense | Passive |
|---|---|
| writes | is written |
| is writing | is being written |
| has written | has been written |
| wrote | was written |
| was writing | was being written |
| had written | had been written |
| will write | will be written |
| will have written | will have been written |

Reported speech: move the tense one step back (is → was, has → had, will → would, did → had done), change pronouns and time words (now → then, today → that day, tomorrow → the next day, yesterday → the previous day, here → there, this → that). Universal truths keep the present tense. Questions take statement order with "if / whether" or the question word. Commands take "to + verb".
