# Logical and Analytical Reasoning: Methods and 100 Practice Problems

Syllabus (Section VII):
- Logical Reasoning: using a rational, systematic series of steps based on sound mathematical procedures and given statements to arrive at a conclusion.
- Analytical Reasoning/Ability: visualising, articulating and solving complex and uncomplicated problems, making sensible decisions based on available information, and applying logical thinking to gathering and analysing information.

The examiner's own comment (CE-2018): most candidates lacked analytical skill and many confused compass directions. These questions are free marks if you draw a diagram and write your steps.

**How to present a reasoning answer:** diagram or table first → numbered deductions, one fact per line → final answer in a box → one-line check against every condition.

# Part 1: Methods

## §1 Series (asked 2018, 2021, 2022, 2023, 2024)

Usually five series for 1 mark each. Write the pattern beside each answer.

**Routine**
1. Write the differences between terms. Constant → arithmetic. Growing by a fixed step → second difference.
2. If differences fail, try ratios (×2, ×3, ÷2).
3. Try squares, cubes, primes, n² ± 1, n(n + 1).
4. Try two operations in turn (×2 then +1; ÷2 then ×3).
5. Try two interleaved series (odd and even positions).
6. Letters: turn into numbers (A = 1 … Z = 26).

| Pattern | Example |
|---|---|
| Constant difference | 5, 9, 13, 17 (+4) |
| Growing difference | 30, 29, 27, 24, 20 (−1, −2, −3, −4) |
| Ratio | 3, 6, 12, 24 (×2) |
| Squares / cubes | 4, 16, 36, 64 (even squares); 1, 8, 27 |
| Products | 0, 2, 6, 12, 20 (n(n − 1)) |
| Alternating operations | 48, 24, 72, 36, 108 (÷2, ×3) |
| Fibonacci | 1, 1, 2, 3, 5, 8 (sum of the two before) |
| Primes | 2, 3, 5, 7, 11 |
| Letter + number | F2, E4, D8, C16 (letter back one, number doubles) |

**Worked (the five series of 2022)**

| Series | Pattern | Missing term |
|---|---|---|
| 4, 16, 36, 64, ?, 144 | Squares of 2, 4, 6, 8, 10, 12 | **100** |
| 30, 29, 27, ?, 20, 15 | −1, −2, −3, −4, −5 | **24** |
| 1, 7, 15, 25, ?, 51 | +6, +8, +10, +12, +14 | **37** |
| 0, 2, 6, 12, 20, 30, ? | +2, +4, +6, +8, +10, +12 | **42** |
| 48, 24, 72, 36, 108, ? | ÷2, ×3 alternately | **54** |

**Worked (2018):** F2, __, D8, C16, B32 → letters go back one; numbers double → **E4**.

Letter positions to memorise: E = 5, J = 10, O = 15, T = 20, Y = 25 ("EJOTY").

## §2 Analogies and classification

- **Analogy (A : B :: C : ?).** State the relation in a sentence ("a doctor works in a hospital") and apply the same sentence to C.

- **Odd one out.** Find the property shared by all but one (prime, square, planet, vowel count).

## §3 Coding and decoding; symbols (asked 2017, 2018, 2019, 2022)

**Routine**
1. Write the word and its code one above the other.
2. Number the letters (A = 1 … Z = 26). Find each shift.
3. If shifts look random, **reverse the word first** and compare again. FPSC has used this twice.
4. Check whether shifts alternate (+4, −2, +4, −2).
5. Apply exactly the same steps to the new word. Show the working.

**Worked (2022).** BROTHER → QDGSNQA. Code SISTER.
Reverse BROTHER: R E H T O R B. Compare with Q D G S N Q A: each letter moves back one.
Rule: reverse the word, then replace each letter by the one before it.
SISTER reversed: R E T S I S → **QDSRHR**.

**Worked (2017 and 2019).** COMPUTER → RFUVQNPC. Code MEDICINE.
Reverse COMPUTER: R E T U P M O C. Code: R F U V Q N P C. The first and last letters stay; the middle six move forward one.
MEDICINE reversed: E N I C I D E M → E, O, J, D, J, E, F, M → **EOJDJEFM**.

**Worked (2018).** LANDMINE → PYRBQGRC. Code HOMEMADE.
L→P (+4), A→Y (−2), N→R (+4), D→B (−2) … shifts alternate +4, −2.
H+4 = L, O−2 = M, M+4 = Q, E−2 = C, M+4 = Q, A−2 = Y, D+4 = H, E−2 = C → **LMQCQYHC**.

**Other code types**
- Opposite letters: A↔Z, B↔Y (position p becomes 27 − p).
- Letter values: word → sum or product of positions.
- Sentence codes: compare sentences that share one word to find that word's code.
- **Symbol substitution:** replace the symbols as defined, then apply BODMAS.

## §4 Blood relations (asked 2017, 2025)

**Notation for a family tree**
- Square or (M) for male, circle or (F) for female.
- Double line "=" for married couple. Vertical line down for children. Horizontal line for brothers and sisters.

**Routine**
1. Start from the person whose relations are given most fully.
2. Add one statement at a time to the tree.
3. Do not assume gender from a name unless told.
4. Read the answer off the tree.

| Phrase | Means |
|---|---|
| My father's or mother's only son (speaker male) | Myself |
| My mother's only daughter (speaker female) | Myself |
| Father's father | Paternal grandfather |
| Mother's brother | Maternal uncle |
| Brother's or sister's son / daughter | Nephew / niece |
| Son's wife | Daughter-in-law |
| Spouse's brother; sister's husband | Brother-in-law |

**Worked.** A and B are a married couple; A is male. D is the only son of C. C is A's brother. E is D's sister. B is the daughter-in-law of F, whose husband has died. How is E related to A?
Tree: F (widow, mother) → sons A and C. A = B. C → children D (son), E (daughter).
E is the daughter of A's brother. **E is A's niece.** (F is A's mother.)

## §5 Direction and distance (asked 2017, 2018, 2021, 2022, 2024)

**Fix the compass first. Draw it on the page.**

```
          N
     NW   |   NE
   W -----+----- E
     SW   |   SE
          S
```

- Facing **north**: right = east, left = west.
- Facing **east**: right = south, left = north.
- Facing **south**: right = west, left = east.
- Facing **west**: right = north, left = south.
- A right turn is 90° clockwise. A left turn is 90° anticlockwise.
- Sun: rises in the east. In the morning shadows point west; in the evening they point east.

**Routine**
1. Draw each leg to rough scale with its length.
2. Add up east–west movement (east +, west −) and north–south movement (north +, south −).
3. Distance from start = √(x² + y²). Give the direction too.

**Worked (2022).** A man walks 110 m east, turns right and walks 40 m, turns right and walks 50 m, turns right and walks 120 m. How far is he from the start?
East 110 → south 40 → west 50 → north 120.
Net east = 110 − 50 = 60. Net north = 120 − 40 = 80.
Distance = √(60² + 80²) = **100 m**, to the north-east of the start.

**Worked (2021).** 90 m east, right 20 m, right 30 m, then 100 m north.
Net east = 90 − 30 = 60. Net north = 100 − 20 = 80. Distance = **100 m**.

**Worked (2018), with a diagonal leg.** 3 km south, 4 km west, 5 km north, 2 km south-east.
A south-east leg of 2 km moves 2/√2 = 1.414 km east and 1.414 km south.
East–west: −4 + 1.414 = −2.586. North–south: −3 + 5 − 1.414 = +0.586.
Distance = √(2.586² + 0.586²) = √7.03 ≈ **2.65 km**.

## §6 Arrangement, ordering and matching puzzles (asked 2016, 2019, 2020, 2026)

**Types and tools**

| Type | Tool |
|---|---|
| Ranking (taller, heavier, older) | A line with > signs |
| Position in a row | Numbered slots; total = left position + right position − 1 |
| Seating in a row | Numbered boxes |
| Seating in a circle | A circle with marked seats |
| Scheduling (order of events) | Slots; treat "immediately after" pairs as one block |
| Matching (person–city–job) | A grid with ticks and crosses |
| Grouping (people into cars or teams) | Columns for each group |

**Routine**
1. List the items and the slots.
2. Place the most definite clue first.
3. Join "next to" or "immediately after" items into a block.
4. Use negative clues (not next to, not last) to remove options.
5. If several cases remain, test each. Cross out the ones that break a rule.
6. Check the final answer against every clue.

**Left and right at a round table.** For people facing the centre, a person's **right is the anticlockwise** direction (seen from above) and **left is clockwise**. State this convention in the answer.

**Worked (2026): circular seating.** Five researchers A, B, C, D, E sit in a circle. A sits second to the right of C. B is not a neighbour of A. D sits opposite C. Build a valid arrangement.

Note first: with five equally spaced seats nobody is exactly opposite anybody. Take "opposite" to mean "across the table, not next to". State that assumption.

1. Number the seats 1–5 clockwise. Put C in seat 1.
2. Right is anticlockwise. Second to the right of C is seat 4. So A is in seat 4.
3. Seats not next to C are 3 and 4. Seat 4 is A's. So D is in seat 3.
4. A's neighbours are seats 3 and 5. B is not a neighbour of A, so B is not in seat 5. B is in seat 2.
5. E takes seat 5.

**Clockwise order: C, B, D, A, E.**
Check: A is two seats anticlockwise from C ✓. B sits between C and D, not next to A ✓. D is across from C ✓.

**Worked (2026): ordering with constraints.** Four machines X, Y, Z, W run one after another. Y cannot run before X. Z runs immediately after W. X cannot be last. List all valid orders.
1. Z immediately after W: treat "WZ" as one block. Items: X, Y, [WZ].
2. Three items can be ordered in 6 ways: X Y WZ, X WZ Y, Y X WZ, Y WZ X, WZ X Y, WZ Y X.
3. Y not before X removes the three with Y ahead of X.
4. Left: X Y W Z, X W Z Y, W Z X Y. In none of them is X last.

**Valid orders: XYWZ, XWZY, WZXY.**

**Worked: comparison (2016, 2020 type).** P is heavier than Q. R is lighter than Q but heavier than S. T is heavier than R but lighter than Q.
P > Q; Q > R > S; Q > T > R. Combined: **P > Q > T > R > S**. Heaviest P; lightest S.

## §7 Deduction and syllogism

**Statement forms**

| Form | Example | Venn picture |
|---|---|---|
| All A are B | All cats are animals | Circle A inside circle B |
| No A is B | No fish is a bird | Two separate circles |
| Some A are B | Some students are athletes | Two overlapping circles |
| Some A are not B | Some birds cannot fly | Part of A outside B |

**Method:** draw the Venn diagram for the statements in every possible way. A conclusion follows only if it is true in **all** the diagrams.

**Quick rules**
- All A are B + All B are C → All A are C.
- All A are B + No B is C → No A is C.
- Some A are B + All B are C → Some A are C.
- All A are B + Some B are C → **nothing** certain about A and C.
- Two "some" statements → no certain conclusion.
- "All A are B" does not give "All B are A". It does give "Some B are A".

**Conditional reasoning: "If P then Q"**

| Given | Conclusion | Valid? |
|---|---|---|
| P is true | Q is true | Valid (modus ponens) |
| Q is false | P is false | Valid (modus tollens) |
| Q is true | P is true | Invalid (affirming the consequent) |
| P is false | Q is false | Invalid (denying the antecedent) |

**Necessary vs sufficient.** "Only graduates may apply" makes a degree necessary, not sufficient.

**Deduction vs induction.** Deduction goes from general rules to a certain conclusion. Induction goes from particular cases to a probable general rule.

## §8 Critical reasoning (new in 2026: three parts in one paper)

**Parts of an argument:** premise (reason given) → conclusion (claim). An **assumption** is an unstated premise that the argument needs.

**Finding assumptions:** ask "what must be true for this reason to lead to this conclusion?" Test by denying it: if the argument collapses, it was an assumption.

**Evaluating strength:** Are the premises true? Do they cover enough cases? Is there another explanation? Is the conclusion wider than the evidence?

**Common fallacies**

| Fallacy | Meaning | Example |
|---|---|---|
| Hasty generalisation | General rule from too few cases | "Two officers were rude, so all officers are rude." |
| Survivorship bias (cherry-picking) | Looking only at the successes | "Famous drop-outs succeeded, so college is useless." |
| False cause (post hoc) | A happened before B, so A caused B | "Sales rose after the new logo, so the logo did it." |
| Ad hominem | Attacking the person, not the argument | "He failed maths, so his budget plan is wrong." |
| Appeal to popularity (bandwagon) | Many believe it, so it is true | "Everyone buys it, so it is best." |
| Appeal to authority | An unqualified "expert" said so | A cricketer endorsing a medicine |
| False dilemma | Only two options offered when more exist | "Ban cars or choke." |
| Slippery slope | One step will surely lead to disaster | "Allow one late paper and nobody will ever be on time." |
| Circular reasoning | Conclusion repeated as the reason | "He is honest because he never lies." |
| Straw man | Attacking a distorted version of the view | |
| Composition / division | What is true of parts must be true of the whole, or the reverse | |

**Worked (2026): assumptions and counter-argument.** Claim: "Artificial intelligence will reduce employment because automation replaces human labour."

*Assumptions:* (1) the jobs automated are not replaced by new kinds of jobs; (2) the amount of work in an economy is fixed; (3) workers cannot retrain; (4) AI replaces whole jobs, not single tasks; (5) cheaper production does not raise demand.

*Strength:* moderate. The premise is true (automation does replace some labour). The conclusion about total employment does not follow, because it ignores job creation. The argument is one-sided.

*Counter-argument:* earlier waves of automation (the power loom, the computer, the ATM) removed some jobs but created more in new fields. AI raises productivity, lowers costs and creates demand for new roles such as data work, AI maintenance and new services. The likely effect is a shift in the kind of work, so the need is retraining, not a fall in total employment.

**Worked (2026): fallacy.** "Because many successful entrepreneurs dropped out of college, formal education is unnecessary for high professional success."

*(i) Fallacy:* hasty generalisation based on survivorship bias. It counts only the famous successes and ignores the far larger number of drop-outs who did not succeed and the graduates who did. It also treats "happened together" as "caused". *Effect on credibility:* the evidence is a handful of exceptions, so the general conclusion is unsupported. The argument is weak.

*(ii) How verbal reasoning helps:* it lets a reader separate premise from conclusion, spot unstated assumptions, notice loaded or vague words ("many", "unnecessary"), ask for representative evidence, test with counter-examples, and restate the claim in a form the evidence supports ("a degree is not the only route to success").

**Worked (2026): decision tree.** Rules: if S1 is present, test for S2. If S2 is absent, rule out the disease. If S3 is present with S2, confirm the diagnosis.

```
                    S1 present?
                   /           \
                 No             Yes
                 |               |
        No test indicated     Test S2
        (rules say nothing)   /      \
                          Absent    Present
                            |          |
                   Disease RULED OUT  S3 present?
                                      /        \
                                    Yes         No
                                     |           |
                             Disease CONFIRMED   Not confirmed:
                                                 observe / further tests
```

Reasoning: S1 is the screening symptom, so it comes first. S2 is necessary: without it the disease is excluded. S2 with S3 is sufficient to confirm. Two branches are not covered by the rules (S1 absent; S2 present without S3); say so and mark them "inconclusive".

**Statement and course of action.** A course of action follows only if it deals with the problem stated and is practical. Reject extreme or unrelated actions.

## §9 Data interpretation (asked 2016, 2017, 2018)

**Routine:** read the title, units and key first → write the figures you need → compute → state the answer with units.

| Chart | Key formulas |
|---|---|
| Pie chart | Value = % × total; angle = % × 3.6°; total = value ÷ its fraction |
| Table | Percentage = part/whole × 100; % change = (new − old)/old × 100 |
| Bar chart / histogram | Read heights; total = sum of bars; modal class = tallest bar |
| Line graph | Slope shows the rate of change |

**Worked (2018 type).** A pie chart shows utilities as 29% of spending. Utilities cost Rs 11,600. Total = 11,600 ÷ 0.29 = **Rs 40,000**. If "other" is 16% and is split savings : entertainment : luxury = 3 : 4 : 1, savings = 3/8 × 16% × 40,000 = **Rs 2,400**.

**Worked (2016 type): grouped frequency table.**

| Distance from depot (km) | Number of stores |
|---|---|
| 21–25 | 10 |
| 26–30 | 22 |
| 31–35 | 28 |
| 36–40 | 14 |
| 41–45 | 6 |

Total stores = 80. Most common band = 31–35 km. Stores 36 km or more away = 14 + 6 = 20. Percentage 31 km or more away = (28 + 14 + 6)/80 × 100 = **60%**.

## Blood relations (41–48)

41. Pointing to a photograph a man says, "She is the daughter of my grandfather's only son." How is the girl related to him?
42. A is B's brother. C is A's mother. D is C's father. How is A related to D?
43. A girl introduces a boy: "He is the son of the daughter of the father of my father's brother." How is the boy related to her?
44. P is the father of Q. Q is the sister of R. R is the husband of S. How is S related to P?
45. A and B are a married couple, A being male. D is the only son of C, who is A's brother. E is D's sister. B is the daughter-in-law of F, whose husband has died. (i) How is F related to A? (ii) How is E related to A?
46. "A + B" means A is the brother of B. "A − B" means A is the sister of B. "A × B" means A is the father of B. What does P × Q − R tell us about P and R?
47. A woman says of a man, "His wife is the only daughter of my mother." How is the man related to her?
48. X's father is Y's son. Z is Y's father. How is Z related to X?

**Solutions 41–48**

41. Grandfather's only son = the man's father. Father's daughter = the man's sister. **Sister**
42. D is C's father; C is A's mother; so D is A's maternal grandfather. A is male. **Grandson**
43. Father of her father's brother = her paternal grandfather. His daughter = her aunt. The aunt's son. **Cousin**
44. R is P's son (Q and R are P's children). S is R's wife. **Daughter-in-law**
45. B is A's wife and is F's daughter-in-law, so A is F's son. (i) **F is A's mother.** C is A's brother and E is C's daughter. (ii) **E is A's niece.**
46. P is the father of Q; Q is the sister of R; so Q and R are siblings. **P is the father of R.**
47. The only daughter of her mother is the woman herself. **He is her husband.**
48. X's father is Y's son, so Y is X's grandfather. Z is Y's father. **Great-grandfather**

## Direction and distance (49–56)

49. A man walks 70 m east, turns right and walks 30 m, turns right and walks 40 m, turns right and walks 70 m. How far is he from the start?
50. A man walks 5 km north, then turns left and walks 12 km. How far and in which direction is he from the start?
51. A car goes 6 km north, 8 km east and then 6 km south. Where is it relative to the start?
52. A man facing north turns 90° clockwise, then 180°, then 45° anticlockwise. Which way does he face?
53. At sunrise a man's shadow falls to his right. Which way is he facing?
54. A is 40 m south-west of B. C is 40 m south-east of B. In which direction is C from A, and how far?
55. A boy walks 40 m west, turns left and walks 30 m, turns left and walks 80 m, turns left and walks 60 m. How far and in which direction is he from the start?
56. Town B is 20 km east of A. C is 15 km north of B. D is 12 km west of C. How far is D from A?

**Solutions 49–56**

49. East 70, south 30, west 40, north 70. Net east 30, net north 40. √(30² + 40²). **50 m**
50. 5 north, 12 west. √(25 + 144) = 13. **13 km, north-west**
51. North and south cancel. **8 km due east**
52. North → east (90° clockwise) → west (180°) → 45° anticlockwise from west is towards south. **South-west**
53. The Sun is in the east, so the shadow points west. West is on his right, so he faces **south**.
54. A is 28.3 m west and 28.3 m south of B; C is 28.3 m east and 28.3 m south. Same level; 56.6 m apart. **C is due east of A, 40√2 ≈ 56.6 m**
55. West 40, south 30, east 80, north 60. Net east 40, net north 30. **50 m, north-east**
56. D is 20 − 12 = 8 km east and 15 km north of A. √(64 + 225) = √289. **17 km**

## Ordering, seating and matching puzzles (57–68)

57. A is taller than B but shorter than C. D is taller than C. E is shorter than B. Who is the tallest, and who is in the middle?
58. In a row of 40 students Ali is 12th from the left. What is his position from the right?
59. Ahmed is 7th from the top and 28th from the bottom of a class. How many students are there?
60. Five people A, B, C, D, E sit in a row facing north. C is in the middle. A is at the left end. B is to the right of C but not at an end. D is not next to A. Give the order from left to right.
61. Six people P, Q, R, S, T, U sit round a table facing the centre. P is opposite S. Q is to the immediate right of P. T is opposite Q. R is next to S. Who sits to the immediate left of P?

63. Five speakers A, B, C, D, E speak in turn. A speaks immediately after C. B speaks first or last. D speaks before E. E is not last. C is not first. (i) List every possible order. (ii) Which is always true: "D speaks before A" or "B speaks last"?
64. Ali, Bilal and Danish are a doctor, an engineer and a teacher (not in that order) and live in Lahore, Karachi and Quetta. The doctor lives in Karachi. Ali is not the doctor and does not live in Quetta. Bilal is the teacher. Find each man's job and city.
65. Box P is heavier than Q. R is lighter than Q but heavier than S. T is heavier than R but lighter than Q. Arrange the boxes from heaviest to lightest.
66. Nine people travel in three cars, three to a car. The girls are A, B, C, D, E and the boys are P, Q, R, S. Each car must have at least one boy. A and B must be together. P and Q must not be together. C must ride with S. Give one valid arrangement.
67. Meetings with managers W, X, Y, Z are held one a day from Monday to Thursday. X is not on Monday. Y is on the day after W. Z is on Thursday. Find the schedule.
68. Three boxes are labelled "Apples", "Oranges" and "Mixed". Every label is wrong. You may take one fruit from one box. Which box do you choose, and how do you label all three?

**Solutions 57–68**

57. D > C > A > B > E. **Tallest D; middle A.**
58. 40 − 12 + 1. **29th**
59. 7 + 28 − 1. **34**
60. Seats 1–5. A = 1, C = 3. B is right of C and not at the end → seat 4. D cannot be seat 2 (next to A) → seat 5. E = 2. **A, E, C, B, D**
61. Number seats 1–6 clockwise; P in 1, S in 4. Right of P is anticlockwise → Q in seat 6. Opposite Q is seat 3 → T. R is next to S: seats 3 and 5 are next to S; 3 is taken → R in 5. U in seat 2. P's immediate left is clockwise → seat 2. **U** (clockwise: P, U, T, S, R, Q)
62. Block [RS]. With P before Q: P Q RS, P RS Q, RS P Q. Q not last leaves one. **P, Q, R, S**
63. Block [CA]. If B is last, the first four are C, A, D, E with CA together, D before E and C not first: D E C A or D C A E. If B is first, E cannot be fifth: D E C A only. (i) **D E C A B; D C A E B; B D E C A.** (ii) D is before A in all three; B is last in only two. **"D speaks before A" is always true.**
64. Bilal is the teacher. Ali is not the doctor → Ali is the engineer → Danish is the doctor and lives in Karachi. Ali is not in Quetta → Lahore. Bilal → Quetta. **Ali: engineer, Lahore. Bilal: teacher, Quetta. Danish: doctor, Karachi.**
65. P > Q; Q > T > R; R > S. **P, Q, T, R, S**
66. One valid answer: **Car 1: A, B, P. Car 2: C, S, D. Car 3: E, Q, R.** Check: each car has a boy; A with B; P and Q apart; C with S. (Other answers exist, for example swapping D and E.)
67. Z is Thursday. W and Y are on consecutive days among Monday–Wednesday. If W is Tuesday and Y Wednesday, X is Monday, which is not allowed. So **W Monday, Y Tuesday, X Wednesday, Z Thursday.**

## Syllogism and deduction (69–78)

For 69–72 say which conclusions follow.

69. All doctors are graduates. Some graduates are athletes. Conclusions: I. Some doctors are athletes. II. Some athletes are graduates.
70. All pens are tools. All tools are objects. Conclusions: I. All pens are objects. II. All objects are pens.
71. No fish is a bird. All sparrows are birds. Conclusions: I. No sparrow is a fish. II. Some birds are sparrows.
72. Some teachers are writers. All writers are readers. Conclusions: I. Some teachers are readers. II. All readers are writers.
73. "If it rains, the match is cancelled." (a) The match was not cancelled. What follows? (b) The match was cancelled. Does it follow that it rained?
74. All A are B. Some B are C. No C is D. Which one follows: (a) Some A are C; (b) Some B are not D; (c) No A is D?
75. Either Ali or Bilal broke the window. Ali was in another city at the time. What follows?
76. All squares are rectangles. All rectangles are quadrilaterals. Figure X is a quadrilateral. Is X a square?
77. "Only graduates can apply for the post." (a) Sara's application was valid. What follows? (b) Ahmed is a graduate. Is he certain to be eligible?
78. A says, "B is lying." B says, "C is lying." C says, "A and B are both lying." Who is telling the truth?

**Solutions 69–78**

69. The athletes among graduates need not be doctors, so I does not follow. "Some graduates are athletes" converts to II. **Only II follows.**
70. Pens are inside tools, which are inside objects. **Only I follows.**
71. Sparrows are inside birds, and birds are separate from fish → I follows. Sparrows are birds → some birds are sparrows (taking sparrows to exist) → II follows. **Both follow.**
72. The teachers who are writers are readers → I. The reverse of "all writers are readers" is not given. **Only I follows.**
73. (a) **It did not rain** (modus tollens). (b) **No.** The match may have been cancelled for another reason (affirming the consequent).
74. The B that are C cannot be D. **(b) follows.** (a) and (c) are not certain: the A's may lie outside C, and some A could be D.
75. One of the two did it and Ali could not have. **Bilal broke the window.**
76. **Cannot be determined.** Every square is a quadrilateral, but not every quadrilateral is a square.
77. (a) **Sara is a graduate.** (b) **No.** A degree is necessary, but other conditions (age, experience) may apply.
78. Suppose A is truthful. Then B lies, so C is truthful, so "A and B are both lying" is true, which contradicts A being truthful. So A lies. Then B is truthful, so C lies; C's statement is indeed false because B is truthful. Consistent. **Only B tells the truth.**

## Critical reasoning (79–86)

79. "The city should build more roads to end traffic jams." State two assumptions behind this argument.
80. "My grandfather smoked all his life and lived to 95, so smoking is not harmful." Name the flaw.
81. "You cannot trust his views on tax policy; he was once fined for speeding." Name the fallacy.
82. "Results improved after the new principal arrived, so the principal caused the improvement." Name the fallacy and give one fact that would weaken the argument.
83. "Online classes are as effective as classroom teaching, because both groups got the same test scores last year." Give one fact that would weaken this and one that would strengthen it.
84. "Either we ban all cars from the city or pollution will destroy us." Name the fallacy.
85. "Everyone is buying this phone, so it must be the best." Name the fallacy.
86. Statement: "Dengue cases rise sharply every year after the monsoon." Courses of action: I. Run an anti-mosquito drive before and during the monsoon. II. Ban all travel between cities after the monsoon. Which follows?

**Solutions 79–86**

79. (1) More road space will reduce congestion and will not simply attract more cars. (2) Lack of road space is the main cause of the jams (not signals, parking or poor public transport). Also: funds and land are available.
80. **Hasty generalisation from a single case (anecdotal evidence; survivorship bias).** One survivor does not outweigh evidence from millions of smokers.
81. **Ad hominem.** It attacks the person; a traffic fine has no bearing on a tax argument.
82. **False cause (post hoc).** Weakeners: the exam was easier that year; brighter students were admitted; new teachers were hired before he came; results rose in all schools.
83. Weakens: the online group were stronger students to begin with; the test was very easy; only one year and one subject were measured. Strengthens: students were assigned to the two groups at random; the result was repeated in several years and subjects.
84. **False dilemma.** Other options exist: cleaner fuel, public transport, congestion charges, electric vehicles.
85. **Appeal to popularity (bandwagon).** Popularity may come from price or advertising, not quality.
86. **Only I follows.** It tackles the cause directly and is practical. II is extreme and does not address mosquito breeding.
