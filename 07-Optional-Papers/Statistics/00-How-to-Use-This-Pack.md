## 3. The answer template that scores

FPSC publishes no marking scheme; this structure makes every mark visible.

**Numerical question**
1. One line naming the method ("Paired t-test, since the same persons are measured twice").
2. For tests, the **six steps**: H₀ and H₁ (in symbols and words) → α → test statistic and its distribution with df → critical value (quote it: t₀.₀₂₅,₃ = 3.182) → computation → decision **and conclusion in words of the problem**.
3. A **table of sums** (Σx, Σx², Σxy; or f, fx, fx²) — examiners check it quickly.
4. Formulas written before numbers.
5. Final answers underlined, with units, rounded sensibly (3–4 significant figures).
6. One sentence of interpretation ("94% of the variation in breakdowns is explained by age").

**Theory question (definitions, comparisons, essays)**
1. Definition in one or two precise sentences.
2. Headings or a comparison table (e.g. sampling vs non-sampling errors).
3. One example for each point — Pakistani examples where natural (PBS surveys, census 2023, CPI).
4. A formula or small numerical illustration if possible.
5. Two-line conclusion.

## 5. Common mistakes (and the fix)

| Mistake | Fix |
|---|---|
| Using n instead of n − 1 (or the reverse) without saying so | State the divisor in one line |
| Wrong df (pooled t: n₁ + n₂ − 2; paired: n − 1; regression: n − 2; χ² GoF: k − 1 − m) | Write the df next to every critical value |
| One-sided vs two-sided confusion (1.645 vs 1.96) | Decide from H₁ before computing |
| Forgetting the FPC in sampling without replacement | Write the formula (σ²/n)(N − n)/(N − 1) every time |
| Not listing all samples in enumeration questions | Count first (ᴺCₙ or Nⁿ), then list systematically |
| ANOVA table without the table F value or conclusion | Always add F_tab and one sentence |
| Using class limits instead of boundaries | Convert to boundaries first |
| Ignoring printed errors in the paper | State your interpretation in one line and proceed |
| Bare numbers in MCQ-style calculations under time pressure | Practise the 20-MCQ section in 25 minutes |
