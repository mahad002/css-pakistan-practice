# Resources — Statistics

Core preparation = **this pack's notes and worked solutions + one Pakistani textbook (Chaudhry & Kamal) + past papers**. Add the free sources below for extra problems and for design of experiments.

**FREE** = free and legal online. **PAID** = buy (cheap local editions exist).

| Resource | Type | How to use |
|---|---|---|

## 3. Paid books (FPSC suggested readings — pick the first, add others only if needed)

| Book | Why |
|---|---|
| **S. Chaudhry & H. Kamal, *Introduction to Statistical Theory*, Parts I and II** (Ilmi Kitab Khana, Lahore) | **The standard Pakistani text and the closest match to CSS questions** (notation, coding method, vital statistics, index numbers, sampling enumeration). Part I: descriptive, probability, distributions, regression; Part II: sampling, estimation, testing, ANOVA, non-parametric |
| R.E. Walpole, R.H. Myers, S.L. Myers, *Probability and Statistics for Engineers and Scientists* | Probability, distributions, inference, regression — strong worked examples |
| D.C. Montgomery, *Design and Analysis of Experiments* | Reference for RCBD, Latin square, relative efficiency |
| R.G.D. Steel & J.H. Torrie, *Principles and Procedures of Statistics* | Agricultural experiments, LSD, the source style of many CSS ANOVA questions |
| J.E. Freund, *Mathematical Statistics* | Derivations (mgf, limits, estimator properties) |
| Hinde, *Demographic Methods* | Fertility, mortality and reproduction rates in depth |

## 4. Tools

| Tool | Use |
|---|---|
| Scientific calculator (statistics mode: Σx, Σx², Σxy, r, a, b) | Allowed in the hall. Practise entering paired data and reading S_xx-type sums; it saves 5–10 minutes per regression question. Check FPSC's current rule on models [verify] |
| A printed set of z, t, χ², F tables (practice only) | Learn to read them; memorise the common values in case none is provided |
