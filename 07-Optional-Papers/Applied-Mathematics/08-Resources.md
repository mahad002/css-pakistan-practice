# Resources — Applied Mathematics

Few books, used hard, beat many books skimmed. The core of preparation is **past papers + this pack's worked solutions + one problem book per section**.

**FREE** = free and legal to use online. **PAID** = buy (most are available in Urdu Bazaar / Pakistani reprints at low cost).

## 1. Official

| Resource | Type | How to use |
|---|---|---|
| FPSC syllabus "CE-2016 and onwards", Applied Mathematics — [fpsc.gov.pk syllabus PDF](https://www.fpsc.gov.pk/uploads/syllabus/1767002683737_Syllabus-for-CE-2016-and-onwards.pdf) | **FREE, official** | The checklist in `01-Syllabus-Checklist.md` follows it. Re-check once in 2027 for any revision |
| FPSC past papers 2023–2026 — [Previous Question Papers / CSS](https://www.fpsc.gov.pk/Schedule?section=Previous%20Question%20Papers/CSS) | **FREE, official** | Print 2024, 2025 and 2026. Sit them timed (3 hours, 5 questions) for the April 2027 gate test |
| Past papers 2016–2025 (transcribed) — [cssprep.com.pk hub](https://cssprep.com.pk/?p=27199) | **FREE** (coaching site) | Use for 2016–2022 practice; numbers are transcribed, so check odd values against a second copy |

| Resource | Covers | How to use |
|---|---|---|

## 3. Paid books (FPSC suggested readings — pick one per row)

| Section | Book | Why |
|---|---|---|
| Vector calculus | Khalid Latif, *An Introduction to Vector Analysis* (FPSC list) | Pakistani text, matches the paper's style and notation |
| Statics & dynamics | Q.K. Ghori, *Introduction to Mechanics*; or Khalid Latif, *An Intermediate Course in Theoretical Mechanics* (FPSC list) | Classic source of the ladder, square-of-forces, central-orbit and projectile problems that CSS repeats |
| ODEs | D.G. Zill & M.R. Cullen, *Differential Equations with Boundary-Value Problems* (FPSC list) | Many CSS ODE and PDE questions closely resemble Zill's examples and exercises (e.g. 2022: largest interval of definition, power series about an ordinary point, plucked string). **Most useful single book** |
| Fourier & PDE | Zill & Cullen (chapters on orthogonal functions, Fourier series and BVPs); or E. Kreyszig, *Advanced Engineering Mathematics* | Kreyszig is the reference for the wave-equation modelling question (2026) |
| Numerical methods | R.L. Burden & J.D. Faires, *Numerical Analysis* (FPSC list) | Source of the bisection x³ + 4x² − 10, fixed-point x⁴ − 3x² − 3 and Gauss–Seidel with rounding questions |
| One-volume revision | S.M. Yusuf, A. Majeed & M. Amin, *Mathematical Methods* (FPSC list) | Covers nearly the whole syllabus at B.Sc. level, cheap, Pakistani |

## 4. Tools

| Tool | Use |
|---|---|
| Scientific calculator (non-programmable, e.g. Casio fx-991 class) | Allowed in the hall. Learn its table mode (for Simpson/trapezoidal values), equation solver (to check roots), and radian setting. Check FPSC's current rule on models before buying [verify] |
| Python or Desmos (practice only) | Check your own answers when practising; never needed in the exam |

## How to use the resources (in order)

1. Notes section in this pack → 2. the matching worked problems in `04-Model-Answers.md` → 3. 10–15 extra problems from Zill / Burden–Faires / Paul's notes → 4. the past-paper questions for that section from `06-Question-Bank.md`, timed.
