# Past papers

Official papers are the best guide to what FPSC asks. Each pack's `02-Past-Paper-Analysis.md` already lists and classifies the 2016–2026 questions in paraphrase; keep the original papers here to practise on the exact wording.

## Where to get them

| Years | Source |
|---|---|
| 2023–2026 | FPSC: https://www.fpsc.gov.pk/Schedule?section=Previous%20Question%20Papers/CSS (official PDFs) |
| 2016–2022 | FPSC no longer hosts them after its Dec 2025 rebuild. Use the links given in each pack's past-paper analysis file and check the wording against at least two sources |
| MPT | FPSC doesn't publish MPT papers. Candidates' recollections are summarised in `../05-MPT-Screening-Test/01-Syllabus-and-Pattern.md` |

## How to file them

Save each paper as `YEAR-Paper.pdf` in its folder, for example `Essay/2026-Essay.pdf` or `Optionals/2025-Political-Science-Paper-I.pdf`.

| Folder | Paper |
|---|---|
| `Essay/` | English Essay |
| `Precis/` | English (Précis & Composition) |
| `General-Science-and-Ability/` | GK-I |
| `Current-Affairs/` | GK-II |
| `Pakistan-Affairs/` | GK-III |
| `Islamic-Studies/` | Islamic Studies |
| `Optionals/` | Your five optional subjects |
| `MPT/` | Your own notes after sitting the MPT |

## Rules for using them

- Keep **2024, 2025 and 2026** unseen until the full timed papers in W44–W51 of the schedule.
- Use 2016–2023 for outlining practice in Phase 2 and Phase 4.
- After the real exam, write down what you remember of each 2028 paper here. It's useful if you sit again.
