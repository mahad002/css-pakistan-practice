# Scorecards for essays, précis and answers

These are practice tools built from the FPSC syllabus, paper instructions and examiners' comments. FPSC publishes no marking scheme, and self-marking runs high, so subtract 5 per paper until a human marker has checked a few of your scripts.

## 3. 20-mark subjective answer (CA, PA, ISL, GSA, optionals)

| Criterion | Max | Score | Note |
|---|---:|---:|---|
| Answers the exact question (command word and limiters) | 4 | | |
| Introduction states the answer in 3–5 lines | 2 | | |
| Headings and logical order | 3 | | |
| Evidence: facts, data, dates, references (Quran/Hadith for ISL), scholars | 5 | | |
| Analysis: causes, effects, both sides, not just description | 3 | | |
| Map, diagram, flowchart or table where it helps | 1 | | |
| Way forward / conclusion that follows from the answer | 2 | | |
| **Total** | **20** | | |

Length guide: about 1,200–1,500 words in 35–40 minutes (check the pack for each paper's timing). An answer under 900 words rarely scores above 10.

## 4. Mark-to-grade guide (for your own trend only)

| Score as % of max | What it usually means |
|---|---|
| Under 40% | Fails the paper. Fix question focus and structure first |
| 40–49% | Pass, but fragile. Add evidence and analysis |
| 50–59% | Strong: well clear of the pass line |
| 60%+ | Excellent. Rare in Essay and Précis |
