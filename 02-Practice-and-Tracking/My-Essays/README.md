# My essays

One file per essay: copy `Essay-01.md` and renumber it. About 45 essays by Feb 2028.

Before each essay:
1. Pick the topic: the schedule row, a past paper in `../../03-Past-Papers/Essay/`, or the 40 practice topics in the Essay pack's `07-Practice-Plan.md`.
2. Write by hand on A4 lined paper, timed. Turn the phone off.
3. Afterwards, photograph the script into this folder, mark it with `../Scorecards.md`, and log faults in `../Error-Log.md`.

Keep the original script untouched. If you rewrite paragraphs, add them under a separate "Revision" heading so you can compare.
