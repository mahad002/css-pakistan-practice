# Study schedule: 1 Feb 2027 → CSS 2028 written exam

Tick each week when done. Missed a week? Don't double up: carry over only the Saturday essay and the Monday/Wednesday reading, and drop that week's extras.

## How to read this

**Weekly slots** (about 15–16 hours): see `00-START-HERE.md`.

| Slot | Time | Default task |
|---|---|---|
| Mon, Wed | 2 h each | Compulsory papers: read the file(s) listed → one-page summary in your own words → one 20-mark answer *outline* (or a full timed answer from Phase 2) |
| Tue, Thu | 2 h each | Optional subjects (A = your 200-mark subject; B1–B4 = your four 100-mark subjects) |
| Fri | 1.5 h | Précis/English drill + Anki vocabulary |
| Sat | 4 h | Essay slot: as listed, then mark it with the Essay pack rubric |
| Sun | 30 min | `02-Practice-and-Tracking/Weekly-Review.md` + dashboard |
| Daily | 20 min | Dawn editorial page → one line in `Current-Affairs-Log.md` |

**Pack codes** (all under `06-Compulsory-Papers/` unless stated):

| Code | Pack |
|---|---|
| ESS | `1-English-Essay/` |
| PRE | `2-English-Precis-and-Composition/` |
