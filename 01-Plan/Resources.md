# Resources: what to use, in what order

Start with what's free and official. Buy books only for gaps this folder doesn't cover, and only one main book per paper. Each pack's own resources file gives more detail.

## 1. Official FPSC (free, always first)

| What | Link | Use |
|---|---|---|
| CSS syllabus (CE-2016 onwards) | https://www.fpsc.gov.pk/uploads/syllabus/1767002683737_Syllabus-for-CE-2016-and-onwards.pdf | Checklist for every paper |
| MPT syllabus | https://www.fpsc.gov.pk/uploads/syllabus/1767073666057_MPT-Syllabus.pdf | Screening-test scope |
| CE Rules 2019 | https://www.fpsc.gov.pk/uploads/mpt-rules/1766991508848_Final_Approved_Rules_CE-2019_and_onwards.pdf | Any question about rules |
| Past papers 2023–2026 | https://www.fpsc.gov.pk/Schedule?section=Previous%20Question%20Papers/CSS | Download into `03-Past-Papers/` |
| Annual reports | https://www.fpsc.gov.pk/Publications?section=Annual%20Report | Pass and fail rates by paper and subject |
| Notices and dates | https://www.fpsc.gov.pk/Jobs?section=CSS | Check from July 2027 |
| Application portal | https://apply.fpsc.gov.pk/login | MPT and written applications |

FPSC rebuilt its site in Dec 2025, so old `assets/media` links are dead. If a link breaks, start from the section pages above.

## 2. Daily and monthly reading

| Source | How |
|---|---|
| **Dawn**: editorial and op-ed pages (dawn.com/opinion) | 20 min a day. One line into `Current-Affairs-Log.md` |
| **The Express Tribune** opinion | 2–3 pieces a week, for a second view |
| **Pakistan Economic Survey** (finance.gov.pk, every June) | Read the overview chapter each June for economy figures |
| **Foreign Affairs**, **The Diplomat**, **Al Jazeera** analysis | 2 long pieces a week from Phase 2 |
| Think tanks: ISSI, IPRI, ISSRA (Pakistan); Brookings, Carnegie, CFR, Crisis Group (world) | When a backgrounder needs depth |
| **Jahangir's World Times (JWT)** (monthly) | Optional. CSS-focused summaries; cross-check facts |

## 3. Books

Buy only if a pack's `COVERAGE.md` shows a gap, and choose one per paper. Titles and editions are from general knowledge; check availability first.

| Paper | Book | Why |
|---|---|---|
| Précis | *Practical English Grammar*, Thomson & Martinet (or Wren & Martin) | Grammar reference |
| Précis | *Précis and Composition*, Hafiz Karim Dad Chughtai | The standard CSS précis book: extra passages |
| Vocabulary | *Word Power Made Easy*, Norman Lewis | Roots-based vocabulary |
| Pakistan Affairs | *The Struggle for Pakistan*, Ayesha Jalal | Scholarly argument for 1947–present |
| Pakistan Affairs | *Pakistan: A Hard Country*, Anatol Lieven | Contemporary society and state |
| Current Affairs | *Pakistan's Foreign Policy: An Historical Analysis*, Abdul Sattar | Foreign-policy history |
| Islamic Studies | *Introduction to Islam*, Dr Muhammad Hamidullah | Concise, reliable overview |
| Optionals | See `07-Optional-Papers/` once built | |

## 4. Tools

| Tool | Use |
|---|---|
| **Anki** (free on Mac; iOS app paid) | Vocabulary, idioms, pairs of words, MPT facts, Quran references. 15 min a day |
| **quran.com**, **sunnah.com** | Check every verse and hadith reference before you memorise it |
| A timer and A4 lined paper | Every timed essay and answer |
| Phone scanner | Photograph your scripts into `02-Practice-and-Tracking/` |
| Claude | Marking, quizzing, updating backgrounders (prompts in `00-START-HERE.md`) |

## 5. People

| Who | How to find | Ask for |
|---|---|---|
| CSS officers who are alumni of your university | Alumni groups, LinkedIn | One essay review a month; a mock interview in 2028 |
| A paid essay checker | Reputable online CSS academies (essay-checking only) | Fortnightly essay feedback from Phase 2 |
| A study partner on the same cycle | CSS forums, LinkedIn | Swap and mark each other's essays and answers |

## 6. What not to spend time on

- **Guess papers and "100% sure" topic lists.** Past-paper analysis in each pack does this honestly.
- **Coaching-site "high-scoring subject" claims.** Several contradict FPSC data (see `04-Research/Optional-Subjects-Research.md`).
- **Full coaching courses.** This folder covers the content; what you need from people is feedback on your writing.
- **Collecting notes you never write from.** Every reading session ends with one timed answer or outline.
