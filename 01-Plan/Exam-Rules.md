# CSS exam rules

Checked 23 Nov 2026 against FPSC's own documents: the CE Rules 2019, the 2021 MPT amendment, the syllabus, the CSS 2027 notices and Annual Report 2023. Every fact, its source link and a confidence tag are in `../04-Research/Official-Facts.md`. Rules can change every year, so re-check fpsc.gov.pk each July.

## 1. Eligibility

| Rule | Detail | You |
|---|---|---|
| Age | 21–30 on **31 Dec of the year before the exam** (Rule 5, 6). +2 years only for set categories (AJK, GB, certain tribal areas, disability, government servants with 2+ years' service). | Eligible for CSS 2028 to CSS 2032 |
| Attempts | 3 written attempts (Rule 11(16)). | 3 left |
| What uses an attempt | Appearing in **any one** written paper, even with a blank answer book. | — |
| What does not | Sitting the MPT. MPT attempts are unlimited within the age limit (Rule 10A(6)). | — |
| Education | Bachelor's degree, 2nd division / grade C or better, HEC-recognised, completed by the cut-off date. | ✅ |
| Nationality | Citizen of Pakistan (or AJK). Marrying a foreign national without government permission bars appointment. | ✅ |
| Domicile | Decides your provincial quota; final once accepted. | Check which domicile you hold |

**Quota shares:** merit 7.5%, Punjab 50%, Sindh 19%, KP 11.5%, Balochistan 6%, ex-FATA 3%, AJK 2%, GB 1%. Within each share there are women and minority sub-quotas.

## 2. Stage 1: MPT (screening test)

| Item | Rule |
|---|---|
| Format | 200 one-mark MCQs, 200 marks. Paper-based OMR (not stated by FPSC; reported) |
| Time | 200 minutes (reported by Dawn; the FPSC scan is unreadable on this line) |
| Split | English 50 · General Abilities 60 · General Knowledge 50 (everyday science, current affairs, Pakistan affairs) · Islamic Studies 20 · Urdu 20 |
| Negative marking | None (reported) |
| Pass mark | **33% (66/200)**. Not counted in final merit |
| Validity | That year's exam only |
| Fee and centre | Rs 250. 19 cities, all in Pakistan. Centre cannot be changed once chosen |
| Pass rate | CSS 2027 MPT: about 91% passed (42,684 of about 47,000, counted from FPSC lists) |

## 3. Stage 2: written exam (1,200 marks)

### Compulsory papers (600)

| Paper | Marks | MCQs | Pass rule |
|---|---|---|---|
| English Essay | 100 | none | 40 |
| English (Précis & Composition) | 100 | 20 | 40 |
| GK-I: General Science & Ability | 100 | 20 | GK-I + GK-II + GK-III together: **120/300** |
| GK-II: Current Affairs | 100 | 20 | (same) |
| GK-III: Pakistan Affairs | 100 | 20 | (same) |
| Islamic Studies (or Comparative Religions) | 100 | 20 | 40 |

### Optional papers (600)

- Exactly 600 marks from Groups I–VII. One subject per group; Group II allows two 100-mark subjects.
- 33% needed in each optional.
- Full list and the recommended choice: `Optional-Subjects.md`.

### Pass rules overall

1. 40 in Essay, Précis and Islamic Studies.
2. 120/300 across the three GK papers.
3. 33% in each optional.
4. **50% aggregate: 600/1,200.**
5. Marks below a paper's pass line are not counted in the total.

### Format rules

| Item | Rule |
|---|---|
| Duration | 3 hours per paper. 200-mark subjects have two papers. |
| MCQs | Answered on a separate OMR sheet, collected after the set time. |
| Language | **English for every paper**, except Islamic Studies (English or Urdu) and the regional-language optionals. An Urdu option for all papers is only a proposal (Sep 2026). |
| Calculators | Only in Applied Maths, Pure Maths, Accountancy, Statistics, Business Administration, Physics, Chemistry. **Not in General Science & Ability.** |
| Ink | Blue or black only. |
| Schedule | One compulsory paper per day since CSS 2026; optionals two sessions a day. CSS 2026 ran 4–15 Feb. |
| Missing a paper | If you miss any paper you can't sit the rest, and the attempt is still used. |
| Fee | Rs 2,200 (online PSID). |
| Re-checking | None. Only a recount, Rs 500 per paper, within one month. |
| Centres | 19 cities in Pakistan; none abroad. |

## 4. Stages 3–4: assessment and interview

| Item | Rule |
|---|---|
| Medical | Medical board (Rs 1,500 fee). |
| Psychological assessment | No marks of its own, but it feeds into the viva marks. |
| Viva voce | 300 marks; **100 needed**. Centres: Islamabad, Karachi, Lahore, Multan, Peshawar, Quetta. |
| Final merit | Written + viva (1,500). Ties go to higher viva marks, then higher compulsory marks, then the older candidate. |
| Groups | 12 occupational groups (PAS, PSP, FSP, IRS, Customs, Audit & Accounts, Commerce & Trade, Information, MLCG, OMG, Postal, Railways). Preferences are given on the form and can be revised once, at the viva. |

- About 225–250 fresh vacancies a year. Only about 170–240 are filled, mostly because women, minority and small-province quota seats go unfilled.
- Normal timing: written result about 6–7 months after the exam; final result about 14–15 months after it.

## 6. Not confirmed (re-check each July)

- Whether a Group I optional is mandatory. The rules say it "can be opted".
- MPT duration and OMR format. Reported by Dawn, not readable in FPSC's scan.
- The exact women's quota percentage.
- Any 2027–28 reform: Urdu option, cluster exams, syllabus revision. None is approved as of Nov 2026, and the age-35 proposal was rejected.
